# Империя туризма

Промо-сайт туристического комплекса на берегу Катуни.

- Адаптивная статическая сборка без зависимостей
- Собственное видео без рекламы встроено вторым экраном в HD с выбором качества
- Действующая система бронирования BookOnline24 открывается прямой ссылкой
- Все реальные категории номеров и коттеджей с фотографиями действующего сайта
- Стилизованная схема территории открывается в полном размере
- Интерактивная Яндекс Карта

Публикация: GitHub Pages из ветки `main`, папка `/(root)`.

Локальный запуск: `python3 -m http.server 8080`
