# Империя туризма

Промо-сайт туристического комплекса на берегу Катуни.

- Адаптивная статическая сборка без зависимостей塱
- Видео RuTube встроено вторым экраномхар
- Действующая система бронирования BookOnline24 открывается внутри сайта
- Реальные категории домов и фотографии с действующего сайта
- Интерактивная Яндекс Карта

Публикация: GitHub Pages из ветки `main`, папка `/(root)`.

Локальный запуск: `python3 -m http.server 8080`
